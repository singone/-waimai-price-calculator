# 外卖门店活动测算工具

基于 Next.js / React 19.2 / Ant Design 6.5 的外卖活动测算工具，用于按门店维护商品、平台规则、门店活动，并测算美团 / 饿了么不同商品组合下的用户实付、活动金额、成本、费用、利润和利润率。

## 运行方式

安装依赖：

```bash
npm install
```

本地开发：

```bash
npm run dev
```

生产构建和静态导出：

```bash
npm run build
```

构建后会生成 `out/` 目录，可用任意静态服务器托管。当前根目录旧版 `index.html`、`js/`、`css/` 保留为迁移前备份，新功能入口以 Next 应用为准。

## 页面结构

- 门店维护：默认展示态查看当前门店信息，点击编辑后维护起送价、配送距离、下单时段、组合枚举参数、费用规则继承、利润率阶梯继承，保存后提交。
- 商品维护：每个门店独立维护商品，字段包括商品名、销售价、成本价、美团价、饿了么价、美团上架、饿了么上架、单点不送。
- 平台通用规则：维护平台佣金、保底佣金、配送费、运费补贴、通用利润率阶梯、基础神券 / 爆红包。
- 美团活动：维护当前门店的美团满减、订单优惠券、神券加码、商品折扣活动。
- 饿了么活动：维护当前门店的饿了么满减、订单优惠券、爆红包加码、商品折扣活动。
- 测算结果：按平台筛选、生成最终商品组合、测算最优活动建议、导出 CSV。
- 风险预警：识别亏损、低利润率、用户实付低于成本的组合，支持只看预警组合和导出 CSV。

## 数据归属

- 商品属于门店，不同门店之间不共享商品。
- 平台价跟随门店商品；美团价或饿了么价为空时默认使用销售价。
- 平台上下架状态跟随门店商品；某个平台下架的商品不参与该平台组合测算。
- 门店满减、订单优惠券、红包加码、商品折扣活动均属于门店。
- 基础神券 / 爆红包阶梯属于平台通用规则，门店不可覆盖。
- 门店默认继承平台费用规则和平台利润率阶梯，也可以切换为门店自定义。
- 浏览器端保存使用 IndexedDB，旧版 localStorage 数据会在读取时自动迁移；后续迁移 PostgreSQL 时可替换存储适配层。

## 计算顺序

```text
平台商品价
- 商品折扣活动
- 门店满减
- 门店订单优惠券
- 平台基础神券 / 爆红包
- 门店红包加码
= 用户实付
```

利润计算：

```text
利润 = 用户实付 - 通用佣金 - 外卖服务费 - 运费补贴 - 商品成本
利润率 = 利润 / 用户实付
```

活动金额：

```text
活动金额 = 商品折扣 + 门店满减 + 门店订单优惠券 + 平台基础红包 + 门店红包加码 + 运费补贴
```

佣金和外卖服务费不计入活动金额。

## 商品折扣活动

商品折扣活动按平台、门店独立维护。

- 多个折扣活动可以同时存在。
- 商品关键字为空时，该活动适用于全部商品。
- 同一商品命中多个活动时，按最大优惠优先。
- 活动自身可设置件数上限。
- 门店可设置整单折扣商品上限；最终会在活动件数上限和整单上限共同约束下选择优惠金额最大的商品生效。

## 最优活动测算

“测算最优活动”基于当前门店和平台筛选反推建议活动：

```text
基础实付 = 平台商品价组合 - 商品折扣 - 基础神券 / 爆红包
```

然后根据当前门店生效的利润率阶梯，寻找让利润率尽量贴近阶梯中位数的用户实付，并拆分为：

- 建议满减
- 建议订单优惠券
- 建议神券 / 爆红包加码

排序目标：

```text
1. 利润率偏离阶梯中位数更小
2. 平均用户实付更低
3. 覆盖组合更多
```

## 风险预警

风险预警基于当前门店和平台筛选下的全部商品组合生成。

触发条件：

```text
1. 利润 < 0
2. 用户实付 < 商品成本
3. 利润率 < 当前实付价所属利润率阶梯最低值 + 安全边际
```

利润率阶梯匹配规则：

```text
最后一个利润率阶梯自动覆盖所有更高实付价。
```

风险等级：

```text
严重：亏损
高：用户实付低于成本
中：利润率低于阶梯阈值
配置：没有可用利润率阶梯
```

测算结果页支持显示预警汇总、过滤最终商品组合为“只看预警组合”，并导出风险预警 CSV。

## 导入和导出

商品维护页支持导入美团 / 饿了么平台商品表：

- 美团商品表按“商品名称”和“外送价”识别。
- 美团商品表按“售卖状态”同步美团上架状态，“售卖中”视为上架，“暂停售卖”等状态视为下架。
- 饿了么商品表按“商品名称”和“价格(元)”识别，导入时不覆盖饿了么上架状态。
- 导入只更新当前门店的对应平台价；已有商品成本价不会被覆盖。
- 已有商品按商品名称匹配更新，新商品会追加到当前门店，成本价默认为 0。

成本表支持 Excel 导入：

- 按“商品名称 / 商品名 / 名称”和“成本价 / 成本 / 商品成本 / 成本(元)”识别。
- 只更新当前门店已有商品的成本价。
- 未匹配到当前门店商品的成本行会跳过，不会自动新增商品。

商品 CSV 字段：

```text
商品名,销售价,成本价,美团价,饿了么价,单点不送
```

也可以追加上下架字段：

```text
商品名,销售价,成本价,美团价,饿了么价,单点不送,美团上架,饿了么上架
```

测算结果和风险预警均支持导出 CSV，导出范围为当前门店和当前平台筛选下的组合结果。

配置支持保存到浏览器，也支持 JSON 导入 / 导出。
