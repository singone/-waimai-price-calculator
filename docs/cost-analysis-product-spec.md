# 成本测算产品说明

## 页面目标

成本测算用于回答：在当前商品售价、打包费、成本、平台基础神券/爆红包和预留优惠空间下，哪些商品在单买或组合购买时利润空间不足。

本页面不是活动配置页面，不自动生成或修改门店活动，也不读取当前门店已配置的满减和订单券。用户填写的满减/券空间就是为后续活动设计预留的折扣空间。

## 用户输入

成本测算参数包含：

- 商品名称筛选：按商品名称模糊匹配。为空时测算全部商品；填写后只输出命中商品及包含该商品的组合。
- 原价小计最低/最高：筛选优惠前整单原价。原价小计包含平台售价和当前平台打包费。
- 支付价最低/最高：筛选最终用户实付。
- 满减/券空间：预留给后续门店满减或订单券设计的金额上限。
- 神券/爆红包加码空间：预留给神券或爆红包加码的额外金额上限。
- 目标利润率：用于判断商品利润率是否低于目标。

## 满减/券空间口径

页面只使用成本测算页填写的满减/券空间：

- 成本测算不读取门店活动维护中的订单优惠券。
- 成本测算不读取门店活动维护中的满减。
- 满减/券空间是用户手动填写的固定预留上限。

示例：

```text
用户填写满减/券空间 = 2
组合明细应展示：
满减/券空间 = 2
优惠总额 = 满减/券空间 + 基础红包 + 加码空间
```

如果组合剩余金额不足 2 元，则满减/券空间按剩余金额扣减。除此以外，系统不能因为当前门店配置了订单券或满减而放大该字段。

## 计算顺序

每个组合按以下顺序计算：

1. 计算原价小计：`(平台商品售价 + 当前平台打包费) * 数量`。
2. 按门店测算总价范围、成本测算原价小计范围、起送价过滤组合。
3. 扣除满减/券空间，实际扣除额不超过用户填写值。
4. 使用扣券后的金额命中平台基础神券/爆红包阶梯。
5. 扣除平台基础神券/爆红包。
6. 扣除神券/爆红包加码空间。
7. 得到用户实付。
8. 扣除佣金、外卖服务费、运费补贴，得到整单到手价。
9. 分摊到商品，计算商品利润和商品利润率。

## 组合明细字段

商品组合明细至少展示：

- 原价小计，含打包费。
- 满减/券空间。
- 基础红包。
- 加码空间。
- 优惠总额。
- 用户实付。
- 平台佣金。
- 外卖服务费。
- 整单到手价。
- 商品到手价。
- 商品成本。
- 商品利润率。
- 剩余空间。

## 验收标准

1. 当用户填写满减/券空间为 `2` 时，组合明细中的“满减/券空间”列不得超过 `2`，除非输入值本身变更。
2. 当前门店配置了满减或订单券时，成本测算结果不得因此变化。
3. “优惠总额”可以大于满减/券空间，因为它是满减/券空间、基础红包和加码空间的合计。
4. 神券/爆红包阶梯必须基于扣除满减/券空间后的金额命中。
5. 原价小计、起送价、原价范围筛选必须包含打包费。
