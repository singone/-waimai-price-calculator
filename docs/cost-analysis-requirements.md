# 成本测算与优惠空间诊断需求文档

## 目标

成本测算用于诊断商品销售价是否能在真实可下单组合中留出足够利润空间。它不是基于单品孤立利润率判断，而是先计算整单组合价格、满减/券预留空间、平台基础神券/爆红包、预留加码空间、佣金、外卖服务费和运费补贴，再把整单结果分摊到商品，形成商品在不同组合和不同支付价下的利润率范围。

## 不参与成本测算的内容

成本测算不使用门店已配置的活动：

- 不使用门店满减。
- 不使用门店订单优惠券。
- 不使用门店神券/爆红包加码。
- 不使用门店商品折扣活动。

成本测算只考虑：

- 商品销售价、平台价、打包费、成本价。
- 平台基础神券/爆红包阶梯。
- 成本测算页输入的商品原价小计范围。
- 成本测算页输入的满减/券预留空间。
- 成本测算页输入的神券/爆红包加码预留空间。
- 佣金、外卖服务费、运费补贴。
- 目标利润率。

## 有效组合规则

只测算真实可下单组合：

1. 商品组合受门店 `最多商品件数`、`单 SKU 最多数量`、`最多检查组合数` 限制。
2. 商品组合受门店 `测算总价范围` 限制，范围按优惠前的平台商品原价小计判断。
3. 商品组合受门店 `主食份数范围` 限制，范围按组合中商品主食份数合计判断。
4. 商品组合受成本测算页 `商品原价小计最低/最高` 限制，用于在成本测算内进一步缩小原价范围。
5. 起送价按商品原价小计判断，低于起送价的组合无效。
6. 组合中必须至少包含一个可单点商品；如果组合全是“单点不送”商品，则组合无效。
7. 平台下架商品不参与对应平台测算。
8. 单个商品如果单买无效，但与其他商品组合后有效，仍计入该商品的成本测算。

## 成本测算参数

成本测算页提供独立参数：

- 商品原价小计最低值。
- 商品原价小计最高值。
- 整单支付价最低值。
- 整单支付价最高值。
- 满减/券预留空间。
- 神券/爆红包加码预留空间。
- 目标利润率。

商品原价小计区间用于筛选优惠前的平台商品原价小计。整单支付价区间用于筛选最终用户实付，不用于筛选单个商品分摊实付。

### 满减/券空间口径

成本测算中的满减/券空间只有一个来源：成本测算页参数。

- 满减/券预留空间：来自成本测算页参数，是用于预留未来门店满减或订单券设计空间的固定上限。

成本测算不得读取当前门店已配置的满减或订单优惠券。若用户填写满减/券预留空间为 `2`，则组合明细中的“满减/券空间”列最大只能显示 `2`，并且优惠总额只汇总满减/券空间、平台基础红包和加码空间。

满减、订单券和满减叠加券的反推属于独立“活动设计”功能，不在成本测算页随诊断一起计算。

## 整单计算口径

对每个有效组合、每个平台执行：

1. 计算平台商品原价小计，原价小计 = `(平台商品售价 + 当前平台打包费) * 数量`。
2. 按成本测算页商品原价小计范围筛选组合。
3. 按原价小计判断起送价。
4. 扣除成本测算页设置的满减/券预留空间。实际扣除额 = `min(满减/券预留空间, 原价小计)`。
5. 使用扣除满减/券空间后的金额命中平台基础神券/爆红包阶梯。
6. 扣除平台基础神券/爆红包。
7. 扣除成本测算页设置的神券/爆红包加码预留空间。
8. 得到整单用户实付。
9. 按整单用户实付筛选支付价区间。
10. 计算佣金、外卖服务费、运费补贴。
11. 扣除佣金、外卖服务费、运费补贴得到整单净实付。
12. 计算整单利润和整单利润率。

整单利润：

```text
整单净实付 = 整单用户实付 - 佣金 - 外卖服务费 - 运费补贴
整单利润 = 整单净实付 - 商品总成本
整单利润率 = 整单利润 / 整单净实付
```

## 商品分摊口径

商品利润率必须来自组合分摊。

分摊基准使用“含打包费原价经过优惠扣减后的商品分摊金额”：

1. 商品原价金额 = `(平台商品售价 + 当前平台打包费) * 数量`。
2. 先按商品原价金额占比，把满减/券预留空间分摊到每个商品。
3. 再使用扣券后商品金额占比，把平台基础神券/爆红包分摊到每个商品。
4. 使用红包后商品金额占比，分摊整单用户实付、佣金、外卖服务费、运费补贴和加码预留空间。
5. 商品分摊成本 = 商品成本价 * 数量。
6. 商品净分摊实付 = 商品分摊用户实付 - 商品分摊佣金 - 商品分摊外卖服务费 - 商品分摊运费补贴。
7. 商品分摊利润 = 商品净分摊实付 - 商品分摊成本。
8. 商品分摊利润率 = 商品分摊利润 / 商品净分摊实付。

说明：

- 单买商品的利润率也是通过同一套整单分摊公式计算。
- 组合越多，同一商品会形成利润率范围。
- 低于目标利润率的组合需要保留明细，方便回查具体组合。

## 商品诊断表

按商品和平台聚合所有有效组合，展示：

- 当前价格。
- 成本价。
- 命中组合数。
- 低于目标组合数。
- 整单净实付最低、最高、平均。
- 商品净分摊实付最低、最高、平均。
- 商品利润率最低、最高、平均。
- 目标利润率。
- 最大可承载优惠空间。
- 建议售价、建议加价和加价比例。
- 异常等级。
- 诊断原因。

## 组合明细二级视图

点击商品后进入或展示该商品明细视图，展示这个商品在当前支付价范围内的所有命中组合：

- 平台。
- 商品组合。
- 整单原价小计，含平台打包费。
- 满减/券空间。
- 平台基础神券/爆红包。
- 神券/爆红包加码预留空间。
- 优惠总额。
- 整单用户实付。
- 整单净实付。
- 商品分摊用户实付。
- 商品净分摊实付。
- 商品分摊成本。
- 商品分摊利润。
- 商品分摊利润率。
- 是否低于目标利润率。

## 建议调价

当商品存在亏损或低于目标利润率的组合时，系统根据该商品所有命中组合中“目标利润率缺口最大”的组合估算建议平台售价。

建议价只作为成本测算页的人工调价建议：

- 用户可以在商品组合分析弹框中修改建议价后应用到当前平台价。
- 应用后写入门店商品的平台价覆盖字段。
- 每次应用都会生成一条成本测算调价记录，记录调前平台价、建议价、调后平台价、相对调前平台价的加价比例、相对商品销售价的加价比例，以及当次测算利润率。
- 应用调价后需要重新生成成本测算，才能看到新价格下的组合利润。

## 异常分级

- 严重：存在商品分摊亏损组合，或所有组合均低于目标利润率。
- 高：平均商品利润率低于目标利润率。
- 中：部分组合低于目标利润率，或最大可承载优惠空间小于 0。
- 正常：所有命中组合均满足目标利润率。

## 导出

成本测算诊断表支持 CSV 导出，组合明细后续可按当前商品导出。

## 非目标

1. 不在用户未确认的情况下自动修改商品价格。
2. 不自动生成优惠券或加码活动。
3. 不读取门店已有满减、订单券、商品折扣或门店神券/爆红包加码配置参与成本测算。
