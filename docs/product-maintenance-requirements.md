# 商品维护需求文档

## 背景

商品维护已经支持单个商品编辑、平台商品表导入、成本表导入、CSV 导入和删除确认。随着门店商品数量增加，逐行修改上下架、单点不送、分类、主食份数、价格和成本效率较低，需要补充批量操作能力。

## 目标

1. 商品维护默认保持详情展示态。
2. 进入编辑态后，支持选择多个商品进行批量操作。
3. 批量操作只修改当前编辑草稿，点击“保存商品”后才提交到门店商品数据。
4. 批量删除需要二次确认，避免误删。
5. 批量编辑需要能覆盖常见高频场景，减少重复操作。
6. 商品分类和主食份数作为门店商品属性维护，用于单人/双人/多人场景下的组合测算边界。

## 批量选择

编辑态商品表支持复选：

- 可选择单行、多行、全选当前页。
- 表格上方显示已选择数量。
- 支持一键清空选择。
- 切换门店、取消编辑、保存商品、替换商品时清空选择。

## 批量操作范围

### 状态类

- 批量设置美团上架/下架。
- 批量设置饿了么上架/下架。
- 批量设置单点不送/允许单点。

### 分类类

- 批量设置商品分类：主食、小吃饮料、加料、套餐、其他。
- 批量设置主食份数。
- 设置分类时，系统按分类和商品名给出默认主食份数，用户可再手动覆盖。

### 价格类

支持字段：

- 销售价
- 成本价
- 美团价
- 饿了么价

支持方式：

- 直接设置为指定金额。
- 按固定金额增减。
- 按折扣系数调整，例如 8.8 表示 8.8 折。

平台价支持批量清空，清空后回到“同销售价”。

### 删除类

- 批量删除选中的商品。
- 删除前显示选中数量和部分商品名称。
- 删除只发生在编辑草稿中，未保存前可以通过取消编辑放弃。

## 交互原则

1. 批量工具条仅在编辑态展示。
2. 未选择商品时，批量操作按钮禁用或提示先选择商品。
3. 批量操作成功后保留选择，方便连续执行多个操作。
4. 删除成功后清空选择，避免选择状态指向已删除商品。
5. 价格批量调整不允许产生负数，最低为 0。

## 非目标

1. 不做跨门店批量操作。
2. 不在详情展示态允许批量修改。
3. 不自动保存批量操作结果。
4. 不新增后端接口。
